01 / Storage model

KV moves responsibility

Ordered keys make lookups and listings direct. The application owns atomic indexes, pagination contracts, and recovery.

02 / Durability

Orphans are recoverable

Publish durable bytes before committing their manifest. Resolve abandoned intents before reclaiming unreferenced data.

03 / Scope

Earn the distributed design

Prove the single-node version with fault injection. Add replication before erasure coding. Defer shared deduplication and sharding until requirements justify them.
